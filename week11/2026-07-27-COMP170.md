Bella asked whether entries can be removed from a file after they've been appended. ## Why We Count Word Frequencies

We connected word-counting to compression, using Morse code as an example: since the letter E is the most common letter in English, it gets the shortest code (a single dot), which keeps messages short and lowers the chance of an error over a noisy channel like an old telegraph wire or a radio signal in a storm.

## From Two Lists to One Dictionary

Rather than keeping one list of words and a second, matching list of counts, Python gives us a single structure called a dictionary, where each word (the key) is paired directly with its count (the value) — like how a student ID uniquely identifies one student.
